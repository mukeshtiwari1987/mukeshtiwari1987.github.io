Install macOS Tahoe on Older Mac

A step-by-step guide to running macOS Tahoe (26) as a virtual machine on unsupported Macs using UTM and an IPSW restore image.

Prerequisites

  • Apple Silicon Mac (M1 or newer) — Intel Macs are not supported for macOS 26
  • macOS Ventura (13) or later as the host OS
  • At least 60 GB free disk space
  • At least 8 GB free RAM to allocate to the VM
  • UTM — latest version installed
  • Xcode 26 Beta — downloaded and extracted
  • macOS Tahoe IPSW — restore image downloaded
Performance Notice: Running macOS in a VM on older hardware will be noticeably slower than native. Allocate at least 8 GB RAM and 60 GB disk for a usable experience. An SSD is strongly recommended.

Step 1 — Install MobileDevice.pkg from Xcode 26

This is the critical step most guides miss. Your host Mac's MobileDevice framework must recognize the Tahoe IPSW format. Without this, UTM will throw "A software update is required to complete the installation."

After extracting Xcode 26 Beta, install the package:

Terminalsudo installer -pkg ~/Downloads/Xcode.app/Contents/Resources/Packages/MobileDevice.pkg -target /
Note: You only need the MobileDevice.pkg — you do not need to install the full Xcode application. After installing the package, the Xcode download can be deleted to free up space.

Step 2 — Open UTM & Create a New VM

  • Launch UTM
  • Click "+" to create a new virtual machine
  • Select "Virtualize" (not Emulate — Apple Silicon uses native virtualization)
  • Choose "macOS 15 Sequoia or later" as the operating system
    (Tahoe is macOS 26 but uses the same virtualization path)

Step 3 — Select the IPSW Boot Image

  • When prompted for the boot image, click Browse
  • Navigate to your downloaded IPSW file:
    UniversalMac_26.4_25E246_Restore.ipsw
  • Select it and click Open
Note: The IPSW filename varies by version. The file should be around 14–18 GB. If yours is significantly smaller, the download may be incomplete.

Step 4 — Configure Hardware

On the hardware configuration screen, allocate resources based on your Mac's available RAM and CPU cores:

ResourceMinimumRecommended
RAM8192 MB (8 GB)16384 MB (16 GB)
CPU Cores46–8 (leave 2 for host)
Storage64 GB80 GB+
DisplayKeep default (1280×800 or higher)
Tip: You can change these later in VM settings, but it's easier to set them now. More RAM = smoother experience.

Step 5 — Complete Setup & Boot

  • Give your VM a name (e.g., macOS Tahoe)
  • Click Save
  • Select the new VM in the sidebar and click the Play button

The VM will boot into the macOS Recovery/Install environment. Follow the on-screen instructions:

  1. Select your language
  2. Click "Install macOS Tahoe"
  3. Agree to the license terms
  4. Select the virtual disk (the 64+ GB disk you created)
  5. Wait for the installation to complete (20–45 minutes depending on hardware)

Step 6 — Set Up macOS

After installation, the VM will reboot into the macOS Tahoe setup assistant:

  1. Choose your country/region and language
  2. Skip sign-in with Apple ID (or sign in if you prefer)
  3. Create a local user account
  4. Disable analytics and Siri if you want a leaner VM
Tip: Sign in with Apple ID to access the App Store and iCloud, but be aware it uses one of your limited device slots.

Step 7 — Install UTM Guest Tools (Optional)

For better integration between host and guest:

  1. In the VM window menu bar, go to Drives > Install Guest Tools
  2. Mount the guest tools ISO inside the VM
  3. Run the installer package from the mounted volume
  4. Restart the VM when prompted

This enables:

  • Shared clipboard (copy/paste between host and guest)
  • Drag-and-drop file sharing
  • Dynamic display resolution

Troubleshooting

"A software update is required to complete the installation"

You skipped Step 1. Install MobileDevice.pkg from Xcode 26 Beta and try again. This is the most common error and the #1 reason the IPSW restore fails.

VM boots to a black screen or UEFI shell

The IPSW may not have been selected correctly. Delete the VM, create a new one, and carefully select the .ipsw file when prompted for the boot image. Do not skip this step.

"This Mac is not supported" during installation

This usually means the IPSW version doesn't match what UTM expects. Make sure you're using the latest UTM version (4.7.5+) and that the IPSW is for Apple Silicon Macs (UniversalMac), not iOS/iPadOS.

Installation is extremely slow

macOS installation in a VM is inherently slow, especially on older hardware. First-time install can take 30–60 minutes. If the progress bar seems stuck, check Activity Monitor on the host — if UTM is using CPU, it's still working. Be patient.

VM kernel panics or crashes repeatedly

Try reducing the allocated CPU cores or RAM. Some older M1 Macs have issues with high core counts in VMs. Also ensure your host macOS is fully updated.

"Can't install the software because it is not currently available from the Software Update server"

This is different from the IPSW error. If this appears inside the VM during a Software Update, it's an Apple server issue. Your host macOS version may need to be updated, or try again later when Apple's CDN is less congested.

Icons missing or UI hangs in the VM

This is a known UTM issue (UTM#7663) where iconservicesagent crashes in the VM. No fix yet from UTM or Apple. The VM is still usable despite missing icons.
